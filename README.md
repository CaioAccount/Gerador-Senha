🔐 **Gerador de Senhas Seguras**

Gerador de senhas seguras desenvolvido com HTML, CSS e JavaScript puro, focado em simplicidade, segurança e performance.

O projeto cria senhas aleatórias utilizando a API de criptografia nativa do navegador (crypto.getRandomValues), garantindo maior segurança na geração dos caracteres.

Sem frameworks, sem bibliotecas externas e sem enviar dados para a internet.

✨ **Funcionalidades**
✅ Geração de senhas aleatórias seguras
✅ Escolha do tamanho da senha
✅ Seleção de tipos de caracteres:
  Letras minúsculas
  Letras maiúsculas
  Números
  Símbolos
✅ Exclusão de caracteres ambíguos
✅ Interface simples e responsiva

📂 **Estrutura do Projeto**
```
📁 gerador
 ├── index.html   # Estrutura da página
 ├── style.css    # Estilos e layout
 └── script.js    # Lógica do gerador de senhas
```

🔒 **Segurança**

As senhas são geradas usando:

crypto.getRandomValues()

Essa API fornece números aleatórios criptograficamente seguros diretamente pelo navegador.

Nenhuma informação é armazenada ou enviada para servidores externos.
